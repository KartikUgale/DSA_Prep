## 📘 Course Overview

**Alpha Curriculum (Java + Data Structures & Algorithms)** by **Apna College** is a comprehensive 4-month program designed to help you master **Java**, **DSA**, and **problem-solving** techniques for top tech company interviews.

---

## 🪶 Topics Covered

### 🟨 **1. Java Programming Basics**
- Flowcharts & Pseudocode  
- Variables & Data Types  
- Conditional Statements (`if`, `switch`)  
- Operators (Arithmetic, Relational, Logical, Assignment)  
- Loops (`for`, `while`, `do-while`)  
- Patterns (Butterfly, Floyd’s Triangle, Rhombus, etc.)  
- Functions & Scope  
- Arrays & 2D Arrays  
- Searching & Sorting (Linear, Binary, Selection, Bubble, Insertion, Count Sort)  
- Strings & `StringBuilder` (in-built methods, storage)

---

### 🟦 **2. Data Structures & Algorithms (DSA)**

#### 🧩 Problem Solving Techniques
- Recursion & Backtracking  
- Divide & Conquer  
- Time & Space Complexity  
- Bit Manipulation

#### ⚙️ Object-Oriented Programming (OOP)
- Classes & Objects  
- Constructors, Getters & Setters  
- Static Members & Function Overloading  
- Abstraction, Encapsulation, Inheritance, Polymorphism  
- Abstract Classes & Interfaces

#### 🔗 Linear Data Structures
- Arrays & ArrayLists  
- Linked Lists (Insertion, Deletion, Merge Sort, Reversal, Midpoint)  
- Stacks & Queues (Array-based, Linked List-based, Circular Queues)

#### 🧮 Advanced Data Structures
- **Heaps / Priority Queues** – Min/Max Heaps, Heap Sort, CBT, PQ Implementation  
- **Hashing (Maps & Sets)** – Insertion, Deletion, Hash Functions, Inbuilt HashMap/HashSet  
- **Tries** – Insert, Search, Delete Operations, Types of Tries, Trie Questions  
- **Segment Trees** – Creation, Range Queries  
- **Dynamic Programming (DP)** –  
  Knapsack, Fibonacci, LCS, Edit Distance, Matrix Chain Multiplication, Catalan Numbers  

#### 🌐 Graphs
- Graph Terminology & Representation  
- DFS, BFS Traversals  
- Weighted & Directed Graphs  
- MST (Kruskal’s, Prim’s)  
- Shortest Path (Dijkstra’s, Bellman-Ford)  
- Cycle Detection & Implementation Problems  

#### 🌲 Trees
- **Binary Trees** – Construction, Traversal, Diameter, Height, LCA  
- **Binary Search Trees (BSTs)** – Search, Insert, Delete, Balanced BST Concepts
